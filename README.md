# Pop-mart

Проект Pop-mart - это веб-приложение для управления коллекцией Pop-mart фигурок.

## Описание

Этот проект позволяет пользователям:
- Просматривать коллекцию Pop-mart фигурок
- Добавлять новые фигурки в коллекцию
- Управлять информацией о фигурках
- Отслеживать свою коллекцию

## Технологии

- Frontend: React.js
- Backend: Node.js/Express
- База данных: MongoDB
- Стилизация: CSS/SCSS

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Letichevsky/Pop-mart.git
cd Pop-mart
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
```bash
npm start
```
